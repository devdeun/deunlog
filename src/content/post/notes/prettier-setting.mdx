## install

```bash
npm install -D prettier @trivago/prettier-plugin-sort-imports
```

## .prettierrc 설정

```json
{
  "plugins": ["@trivago/prettier-plugin-sort-imports"],
  "importOrder": [
    "^(react/(.*)$)|^(react$)",
    "^(next/(.*)$)|^(next$)", // react 프로젝트에서는 생략
    "^@/(.*)$",
    "^[./]"
  ],
  "importOrderSeparation": true,
  "importOrderSortSpecifiers": true,
  "printWidth": 100,
  "tabWidth": 2,
  "semi": false,
  "singleQuote": true,
  "endOfLine": "auto"
}
```

### \@trivago/prettier-plugin-sort-imports

`import 구문`을 자동으로 정렬해 주는 플러그인

- `importOrder`: import 문의 정렬 순서를 지정
- `importOrderSeparation`: true로 설정하면 import 그룹 사이에 빈 줄 추가
- `importOrderSortSpecifiers`: import 구문 내부의 항목들을 알파벳순으로 정렬
